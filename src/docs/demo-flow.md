# Demo script (~4 minutes)

1. **Landing** — “See it. Verify it. Resolve it.” Open public issues (no PII).
2. **Citizen** — Demo login `citizen@demo.civicverify`. Start a report. Allow GPS or show denial → needs review.
3. **Camera** — Capture in-app. Explain gallery is disabled for this flow.
4. **Duplicates** — Seed includes a nearby garbage issue; attach vs create.
5. **Verification** — Show score, flags, language (“verified with low risk”).
6. **Officer** — North officer queue; accept; IN_PROGRESS; upload after-photo; resolve.
7. **Authority** — Escalated list + audit timeline.
8. **Honesty close** — “We assess evidence risk. We do not prove reality.”
